# سجل مواد القنيطرة

تطبيق ويب لتسجيل المواد المنتَجة في **مديرية إعلام القنيطرة — دائرة الإنتاج**، وتصدير
تقارير الإنجاز بنفس قالب Excel المعتمد في المديرية.

- كل موظف يسجّل موادّه ويرى موادّه هو فقط.
- الأدمن يرى الجميع، ينشئ الحسابات، يحدّد الصلاحيات، ويصدّر تقريراً لأي موظف بين أي تاريخين.
- التطبيق يتذكّر آخر تقرير صدّرته ويذكّرك من وين تكمّل.

---

## أين تعيش الحماية

> الفصل بين الموظفين **ليس** في جافاسكربت. هو في سياسات RLS داخل Postgres.
> لو فتح موظف أدوات المطوّر وحذف كل الشروط من الكود وطلب كل الصفوف،
> ترجع له قاعدة البيانات **موادّه هو فقط**. لا يوجد مسار آخر إلى البيانات.

المفتاح العام (`anon key`) في `src/config.js` مكشوف بالتصميم — هذا طبيعي وآمن.
المفتاح الخطير (`service_role`) لا يوجد في المستودع إطلاقاً؛ يبقى داخل Supabase
وتستعمله الـEdge Function وحدها على السيرفر.

---

## التنصيب — ٦ خطوات

### ١. مشروع Supabase

افتح [supabase.com](https://supabase.com) → **New project**.

> **مهم:** أنشئ مشروعاً **جديداً** مخصّصاً لهذا التطبيق. لا تستعمل مشروعاً فيه
> تطبيق آخر — الجداول هنا اسمها `profiles` و`entries`، وقد تصطدم بجداول موجودة.

من **Project Settings → API** انسخ:
- **Project URL** → إلى `SUPABASE_URL` في `src/config.js`
- **anon / publishable key** → إلى `SUPABASE_ANON_KEY` في نفس الملف

### ٢. الجداول والحماية

**SQL Editor → New query** → الصق محتوى `supabase/migrations/0001_init.sql` → **Run**.

ينشئ الجداول والصلاحيات وسياسات RLS. شغّله مرة واحدة.

### ٣. الدالتان

من لوحة Supabase: **Edge Functions → Deploy a new function → Via Editor**.
انشر اثنتين، الاسم بالضبط كما هنا:

| الاسم | الملف | تعمل ماذا |
|---|---|---|
| `admin-users` | `supabase/functions/admin-users/index.ts` | إنشاء الحسابات وتغيير كلمات السر وحذفها |
| `fb-lookup` | `supabase/functions/fb-lookup/index.ts` | قراءة عنوان المادة من رابط فيسبوك |

لنسخ ملف إلى الحافظة: `cat supabase/functions/<الاسم>/index.ts | pbcopy`

> **بعد نشر كل دالة:** ادخل **Settings** وأطفئ **Verify JWT with legacy secret**
> ثم **Save changes**. الدالتان تتحققان من هوية المتصل بنفسيهما (توكن صالح +
> أدمن مفعَّل)، والتحقق القديم يرفض جلسات نظام المفاتيح الجديد قبل أن تصل
> إلى الكود. تركه مفعَّلاً يعني فشلاً بلا رسالة مفهومة.

بديلاً، عبر `npx` بدون تنصيب:

```bash
npx supabase login
npx supabase link --project-ref <رقم-مشروعك>
npx supabase functions deploy admin-users
npx supabase functions deploy fb-lookup
```

### ٤. حساب الأدمن الأول

مشكلة البيضة والدجاجة: إنشاء الحسابات يحتاج أدمن، وما في أدمن بعد. فالأول يدوي:

**أ.** **Authentication → Users → Add user**
- Email: `admin@users.quneitra-media.app`
- Password: كلمة سر قوية — احفظها
- فعّل **Auto Confirm User**

**ب.** **SQL Editor** → الصق `supabase/migrations/0002_bootstrap_admin.sql` → **Run**

**ج.** في نفس المحرّر شغّل (بعد تبديل اسمك):

```sql
select public.bootstrap_admin(
  'admin@users.quneitra-media.app',
  'admin',
  'اسمك الكامل'
);
```

الدالة ترفض العمل مرة ثانية إذا صار في أدمن — فما في خطر تشغيلها بالغلط.

### ٥. الرفع على GitHub

```bash
cd quneitra-media-log
git add -A
git commit -m "سجل مواد القنيطرة"
git push -u origin main
```

ثم في المستودع: **Settings → Pages** → Source: **Deploy from a branch** →
Branch: `main` / `/ (root)` → **Save**.

بعد دقيقة يصير التطبيق على:
`https://<اسم-حسابك>.github.io/<اسم-المستودع>/`

### ٦. أول دخول

افتح الرابط → `admin` + كلمة السر → تبويب **الحسابات** → أنشئ حسابات الموظفين.

كلمة سر كل موظف تظهر **مرة واحدة** عند الإنشاء. انسخها وابعتها له.

## الاستعمال

**تسجيل مادة:** الصق في «لصق سريع» ما نسخته من فيسبوك (الرابط ونص المنشور معاً).
التطبيق يفصل الرابط، ويقرأ تاريخ النشر من النص، ويقترح عنواناً. كلها قابلة للتعديل.

**التقارير:** حدّد الفترة (أو اضغط «منذ آخر تقرير») ثم **تصدير ملف Excel**.
الملف يطابق قالب المديرية: الجدول والأعمدة والتعبئة الصفراء واتجاه اليمين-لليسار،
التواريخ تواريخ حقيقية يقرأها Excel، الروابط قابلة للنقر، وخانة «عدد المواد» تُحسب تلقائياً.

**حذف حساب:** مواد الموظف تبقى محفوظة باسمه ويراها الأدمن ويصدّرها. مغادرة الموظف
لا تلغي إنجازه.

---

## حدود معروفة

**تاريخ النشر ونص المنشور لا يمكن جلبهما من رابط فيسبوك تلقائياً.** فيسبوك يرجّع
صفحة تسجيل دخول لأي طلب غير مسجَّل. حتى الواجهة الرسمية (Graph API) تحتاج تطبيق
فيسبوك وتوكن صفحة تملكها. لذلك يأتيان من النص الملصوق — والتطبيق يقرأ التاريخ منه
بعشرين صيغة (عربية وإنكليزية، مطلقة ونسبية: `٩ أيلول`، `أمس`، `منذ ٣ أيام`، `2d ago`).

**العنوان يُجلب من الرابط** عبر `fb-lookup`: الصق رابط الفيديو واضغط «جِب البيانات
من الرابط». الدالة تقرأ بطاقة المشاركة من جهة السيرفر (المتصفح ممنوع من طلب
facebook.com). هذا مسار احتياطي يقدّم نفسه كزاحف فيسبوك، وقد يتوقف دون إنذار.

**المسار الرسمي** يحتاج توكن صفحة: إن صار لديك صلاحية إدارة على الصفحة، ضع
التوكن في **Edge Functions → Secrets** باسم `FB_PAGE_TOKEN`. عندها تنتقل الدالة
تلقائياً إلى Graph API وتجلب **العنوان والتاريخ ومدة الفيديو** — بلا أي تعديل في
الكود.

**زر «اقترح عنواناً»** بديل بلا إنترنت: ينظّف أول جملة من النص الملصوق من
الهاشتاغات والإيموجي.

## بنية المشروع

```
index.html                     الواجهة
assets/styles.css              التنسيق
src/config.js                  رابط ومفتاح Supabase  ← عبّيه
src/api.js                     الاتصال بقاعدة البيانات
src/app.js                     منطق الواجهة
src/dates.js                   قارئ تاريخ النشر من نص المنشور
src/xlsx.js                    مُصدِّر Excel
vendor/template.b64.js         قالب المديرية الأصلي
supabase/migrations/           الجداول وسياسات الحماية
supabase/functions/admin-users/ إنشاء الحسابات (سيرفر)
supabase/functions/fb-lookup/    قراءة بيانات المادة من رابط فيسبوك
```

## تشغيل محلي

الملفات وحدات ES، فلا تعمل بفتح `index.html` مباشرة. شغّل خادماً بسيطاً:

```bash
python3 -m http.server 8080
```

ثم افتح `http://localhost:8080`.

## مصائد وقعنا فيها — لئلا تتكرر

**١. محرّر SQL ينفّذ السكربت كصفقة واحدة.** أي `raise exception` في المنتصف يسحب
معه `create function` الذي فوقه، فتختفي الدالة بصمت. لهذا صار تفعيل الأدمن الأول
أمر `insert` مباشراً لا دالة.

**٢. `Verify JWT with legacy secret`.** يجب أن يكون **مطفأً** على كل دالة.

**٣. ترويسات CORS.** مكتبة `supabase-js` ترسل `apikey` و`x-client-info` مع كل نداء
دالة. إن لم تُذكرا في `Access-Control-Allow-Headers` يلغي المتصفحُ الطلبَ في الفحص
المسبق، فلا يصل شيء إلى السيرفر ولا يعود رد يُقرأ سببه. **ولا يظهر هذا العطل في
`curl` إطلاقاً** لأنه لا يجري فحصاً مسبقاً — فاختبر من متصفح لا من سطر الأوامر.
